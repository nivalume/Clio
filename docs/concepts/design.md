# 界面设计

Clio 网站的界面是粗野主义（brutalist）风格：暖灰色纸面、墨色顶栏、2px 描边、硬边偏移阴影、平涂色块，每个面板像一个插着标签的档案夹。主色是钴蓝，主要操作用番茄红。这一页说明这些元素是什么、为什么这样选。要改外观，见 [[customizing]] 和 [[config#主题]]。

## 为什么是这种风格

知识库页面信息密度高：正文、大纲、关系、反向链接、局部图谱同时出现。这种风格在这里有三个实际好处：

- **边界清楚。** 每个面板有完整的墨色描边和一个标签，几块内容并排时一眼能分开，不靠细微的灰度差。
- **颜色只用来编码。** 背景是中性的纸色和墨色，彩色只出现在有含义的地方：钴蓝表示选中和当前位置，番茄红表示主要操作，其余颜色表示笔记类型。
- **对比度高。** 墨色配纸色、深色墨配类型色，在浅色和深色两种主题下都容易读，数值见下文 [[#无障碍]]。

深色主题对调纸和墨，钴蓝调亮一档；类型色在两种主题里不变。类型色上的文字和图案始终用深色墨（`--on-candy`），因为浅色文字放在这些颜色上对比度不够。钴蓝在浅色主题里配白字，在深色主题里配深色字（`--on-cobalt`）。错误色和番茄红分开：番茄红是按钮，错误色只出现在检查结果和坏掉的链接上。完整的变量列表见 [[config#主题]]。

## 字体

| 用途 | 字体 | 回退 |
|---|---|---|
| 正文、标题、界面 | Space Grotesk | 苹方、冬青黑体、微软雅黑、思源黑体，最后是系统无衬线字体 |
| 代码、元信息、标签、日期 | Space Mono | 系统等宽字体，中文回退到苹方和思源黑体 |

Space Grotesk 是几何无衬线体，字形宽、有个性，和粗描边相配。元信息（id、类型、日期、计数）一律用等宽字体，与正文明显区分。两种字体都只覆盖拉丁字符，中文由回退字体显示，所以中英文混排时中文仍然是常见的黑体。

## 描边、阴影和网点

- 描边：所有面板、按钮、输入框都是 2px 墨色实线。
- 硬阴影：不模糊，向右下偏移，三档为 2px、4px、6px（`--shadow-sm`、`--shadow`、`--shadow-lg`）。按钮按下时阴影收回，像被按进纸面。墨色顶栏上的按钮看不见墨色阴影，改用钴蓝阴影。
- 网点阴影：重要的面板在硬阴影之外，再加一层圆点网格，偏移约 15px，模仿印刷品的网点。
- 圆角：面板和标签 8px（`--radius`），标签和头像 4–6px，按钮和输入框是直角。

## 档案夹标签面板

界面上的每个面板（搜索、正文、关系、图谱、检查结果）都是同一个组件：一个面板，上沿插着一个或几个标签，像档案夹。

```text
 +=======+ +-------+ +-------+
 | tab 1 | | tab 2 | | tab 3 |                 tools
 |       +-+-------+-+-------+----------------------+
 |                                                  |
 |  body                                            |
 |                                                  |
 +--------------------------------------------------+
```

| 部分 | 说明 |
|---|---|
| 标签 | 2px 描边、没有下边、上面两个角是 8px 圆角。当前标签用卡片底色，盖住面板的上边框，和面板连成一体；其余标签用 `--paper-2` 底色，下边贴着面板上沿 |
| 色条 | 当前标签顶部的 4px 色条。笔记页用笔记类型的颜色，其他面板用钴蓝或这个面板的标识色 |
| 标题标签 | 只有一个标签时，它就是面板的标题：一个 20px 的彩色小方块（里面是符号）、粗体标题、等宽小字的副标题（计数、id 之类） |
| 工具 | 标签行右侧的按钮，例如打开图谱、编辑；手机宽度下折到标签下方 |
| 内容区 | 卡片底色，左上角是直角（标签接在这里），其余三角 8px 圆角，6px 硬阴影 |

有几个标签时，它们切换同一个面板里的内容：笔记页是「正文 / 关系 / 信息」，图谱页是「图谱 / 表格」。标签是 `role="tablist"` 里的按钮，左右方向键在标签之间移动。

统一用一个组件，读者只需要学一次：标签告诉你这是什么、现在看的是哪一页，内容区是内容本身。

## 像素头像

每种笔记类型有一个 8×8 像素的头像：底色是这种类型的颜色，上面用墨色像素画一个简单的图形。头像出现在笔记标题旁、列表项前、搜索结果和链接预览里。

8×8 的网格足够画出能区分的图形，又小到在 16px 的列表行里也清晰；用 SVG 的 `crispEdges` 绘制，任何缩放下像素都不会模糊。

## 类型的编码

类型是这个界面最重要的分类信息，所以它被同时编码三次：

| 编码 | 出现在 |
|---|---|
| 类型色 | 头像底色、图谱节点填充、列表里的类型标签、笔记页当前标签的色条 |
| 形状 | 图谱节点的形状：主题和指南是星形，概念是圆，实体和参考是方块，来源是三角，问题是菱形，日志是十字 |
| 文字 | 类型名（「概念」「来源」……），在标签、图例和筛选器里 |

只靠颜色区分时，色觉障碍的读者、黑白打印和低质量的屏幕都会出问题。加上形状和文字，任何一种编码失效时，另外两种仍然可用。图谱的图例列出每种类型的颜色和形状，见 [[knowledge-graph#图谱视图]]。

## 浅色与深色

- 第一次访问时跟随操作系统的设置（`prefers-color-scheme`）。
- 读者在顶栏切换后，选择保存在浏览器本地，之后不再跟随系统；无法写入本地存储时（如隐私模式），切换只在这次访问内有效。
- 不运行 JavaScript 时，页面仍然按系统设置显示正确的主题，因为深色变量写在 CSS 媒体查询里。
- 代码高亮在构建时生成浅色和深色两套，切换主题不需要重新渲染。

## 无障碍

- **类型不只靠颜色。** 颜色、形状、文字三重编码，见上文。
- **键盘可以完成所有操作。** 所有交互元素都是原生的按钮和链接，按 Tab 键的顺序与视觉顺序一致；面板的标签用左右方向键切换。键盘焦点显示为 3px 钴蓝外框，鼠标点击时不显示（`:focus-visible`）。
- **减少动画。** 系统开启「减少动态效果」（`prefers-reduced-motion`）时，所有过渡和动画都关闭。
- **对比度。** 按 WCAG 计算，正文文字都在 4.5:1 以上：墨色配纸色 15.9:1，元信息配次级背景 4.9:1，类型色上的深色墨最低 5.9:1（番茄红），钴蓝底上的白字 5.1:1，错误色上的白字 5.0:1；深色主题里墨色配卡片 14.8:1，钴蓝底上的深色字 6.2:1。
- **语义结构。** 面板是 `section`、`nav`、`aside` 等语义元素，并通过 `aria-labelledby` 关联标题；装饰性的符号和头像对屏幕阅读器隐藏。
- **没有 JavaScript 也能读。** 每篇笔记都有完整的静态 HTML，见 [[architecture#为什么是静态网站]]。
