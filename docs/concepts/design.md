# 界面设计

Clio 网站的界面是粗野主义（brutalist）加 Y2K 网页聊天室的风格：米色纸面、黑色 2px 描边、硬边偏移阴影、平涂的糖果色，每个面板画成一个聊天窗口。这一页说明这些元素是什么、为什么这样选。要改外观，见 [[customizing]] 和 [[config#主题]]。

## 为什么是这种风格

知识库页面信息密度高：正文、大纲、关系、反向链接、局部图谱同时出现。这种风格在这里有三个实际好处：

- **边界清楚。** 每个面板有完整的黑色描边和标题栏，几块内容并排时一眼能分开，不靠细微的灰度差。
- **颜色只用来编码。** 背景是中性的纸色，糖果色只出现在有含义的地方：笔记类型、主要操作、选中状态、高亮。
- **对比度高。** 黑字配米色纸、黑字配糖果色，在浅色和深色两种主题下都容易读。

## 色板

| 变量 | 浅色 | 深色 | 用途 |
|---|---|---|---|
| `--paper` | `#fffaef` | `#141111` | 页面背景 |
| `--paper-2` | `#fbf1da` | `#1b1716` | 次级背景：侧栏、表头、代码块 |
| `--card` | `#ffffff` | `#1f1a19` | 窗口内容区和卡片 |
| `--ink` | `#141111` | `#fffaef` | 文字、描边、硬阴影 |
| `--ink-2` | `#3b3534` | `#e2d9c9` | 次要文字 |
| `--muted` | `#6b6461` | `#aaa194` | 元信息 |
| `--yellow` | `#ffd440` | 同左 | 顶栏、窗口图标、选中 |
| `--pink` | `#fe7da8` | 同左 | 主要操作按钮、键盘焦点框 |
| `--cyan` | `#27ccf3` | 同左 | 类型色 |
| `--lime` | `#a9d877` | 同左 | 类型色、成功 |
| `--lavender` | `#bbafe6` | 同左 | 类型色 |
| `--orange` | `#f8a16f` | 同左 | 类型色 |
| `--red` | `#f97264` | 同左 | 错误 |
| `--highlight` | `#ffe58f` | `#5b4a12` | `==高亮==` 和搜索命中 |

深色主题把纸和墨对调，糖果色保持不变。糖果色上的文字和图案始终用深色墨（`--on-candy`，`#141111`），因为浅色文字放在黄色或青色上对比度不够。完整的变量列表见 [[config#主题]]。

## 字体

| 用途 | 字体 | 回退 |
|---|---|---|
| 正文、标题、界面 | Space Grotesk | 苹方、冬青黑体、微软雅黑、思源黑体，最后是系统无衬线字体 |
| 代码、元信息、标签、日期 | Space Mono | 系统等宽字体，中文回退到苹方和思源黑体 |

Space Grotesk 是几何无衬线体，字形宽、有个性，和粗描边相配。元信息（id、类型、日期、计数）一律用等宽字体，与正文明显区分，像聊天软件里的时间戳。两种字体都只覆盖拉丁字符，中文由回退字体显示，所以中英文混排时中文仍然是常见的黑体。

## 描边、阴影和网点

- 描边：所有面板、按钮、输入框都是 2px 墨色实线。
- 硬阴影：不模糊，向右下偏移，三档为 2px、4px、6px（`--shadow-sm`、`--shadow`、`--shadow-lg`）。按钮按下时阴影收回，像被按进纸面。
- 网点阴影：重要的窗口在硬阴影之外，再加一层半透明的圆点网格，偏移约 15px，模仿印刷品的网点。
- 圆角：窗口 10px，其余元素基本是直角。

## 聊天窗口组件

界面上的每个面板（搜索、正文、关系、图谱、检查结果）都是同一个窗口组件，结构固定：

```text
┌───────────────────────────────────────────────────────┐
│ ┌──┐                                                  │
│ │ #│  标题  副标题                    工具   ■ □ □    │  ← 标题栏
│ └──┘                                                  │
├───────────────────────────────────────────────────────┤
│  选项卡 1 │ 选项卡 2 │ 选项卡 3                        │  ← 可选：选项卡
├───────────────────────────────────────────────────────┤
│                                                       │
│  内容                                                 │
│                                                       │
└───────────────────────────────────────────────────────┘▓
  ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓  ← 硬阴影
```

| 部分 | 说明 |
|---|---|
| 图标方块 | 32px 黄色方块，2px 墨色描边，里面是 `#`（像聊天室的频道符号）或一个像素头像 |
| 标题和副标题 | 标题是粗体；副标题用等宽小字，放 id、计数之类的元信息 |
| 工具 | 标题栏右侧的按钮，例如复制链接、展开 |
| 窗口圆点 | 三个 8px 小方块，第一个实心：■□□。纯装饰，屏幕阅读器忽略它们 |
| 选项卡 | 标题栏下方一行，同一窗口里切换视图，例如「关系 / 链接到这里 / 局部图谱」 |
| 内容区 | 白色卡片底（深色主题下为深色），18–20px 内边距 |

统一用一个组件，读者只需要学一次：标题栏告诉你这是什么，内容区是内容本身。

## 像素头像

每种笔记类型有一个 8×8 像素的头像，像聊天室里的用户头像：底色是这种类型的糖果色，上面用墨色像素画一个简单的图形。头像出现在笔记标题旁、列表项前、搜索结果和链接预览里。

8×8 的网格足够画出能区分的图形，又小到在 16px 的列表行里也清晰；用 SVG 的 `crispEdges` 绘制，任何缩放下像素都不会模糊。

## 类型的编码

类型是这个界面最重要的分类信息，所以它被同时编码三次：

| 编码 | 出现在 |
|---|---|
| 糖果色 | 头像底色、图谱节点填充、列表里的类型标签 |
| 形状 | 图谱节点的形状，每种类型不同 |
| 文字 | 类型名（「概念」「来源」……），在标签、图例和筛选器里 |

只靠颜色区分时，色觉障碍的读者、黑白打印和低质量的屏幕都会出问题。加上形状和文字，任何一种编码失效时，另外两种仍然可用。图谱的图例列出每种类型的颜色和形状，见 [[knowledge-graph#图谱视图]]。

## 浅色与深色

- 第一次访问时跟随操作系统的设置（`prefers-color-scheme`）。
- 读者在顶栏切换后，选择保存在浏览器本地，之后不再跟随系统；无法写入本地存储时（如隐私模式），切换只在这次访问内有效。
- 不运行 JavaScript 时，页面仍然按系统设置显示正确的主题，因为深色变量写在 CSS 媒体查询里。
- 代码高亮在构建时生成浅色和深色两套，切换主题不需要重新渲染。

## 无障碍

- **类型不只靠颜色。** 颜色、形状、文字三重编码，见上文。
- **键盘可以完成所有操作。** 所有交互元素都是原生的按钮和链接，按 Tab 键的顺序与视觉顺序一致。键盘焦点显示为 3px 粉色外框，鼠标点击时不显示（`:focus-visible`）。
- **减少动画。** 系统开启「减少动态效果」（`prefers-reduced-motion`）时，所有过渡和动画都关闭。
- **对比度。** 正文是墨色配纸色；糖果色上一律用深色墨。
- **语义结构。** 窗口是 `section`、`nav`、`aside` 等语义元素，并通过 `aria-labelledby` 关联标题；装饰性的圆点和头像对屏幕阅读器隐藏。
- **没有 JavaScript 也能读。** 每篇笔记都有完整的静态 HTML，见 [[architecture#为什么是静态网站]]。
