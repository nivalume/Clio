# __TITLE__：给 Agent 的约定

这是一个用 Clio 写的文档站。通用的工作流程在 `skills/clio/SKILL.md`；这份文件写这个文档站的约定，两者冲突时以这里为准。

## 页面类型

- `guides/`：指南，一页完成一件事，按步骤写（`:::steps`），每步可以照着做。
- `reference/`：参考，完整列出选项、参数、字段，用表格，不讲故事。
- `concepts/`：概念，解释为什么这样设计、各部分怎样配合。

## 写法

- 页面 id 用英文 kebab-case，与文件名相同。
- 每页写一句 `summary`，说明读者从这一页得到什么。
- 示例要能直接运行；命令和输出分开写。
- 链接到其他页面用 `[[id]]`，链接到小节用 `[[id#小节标题]]`。
- 修改中文原文后，运行 `clio translate-status`，同步更新英文译文并 `--pin`。

## 每次修改之后

- `clio check` 没有错误。
- 在 `log.md` 追加 `## [YYYY-MM-DD] edit | 标题`。
